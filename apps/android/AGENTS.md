# apps/android

Native Android app on Expo SDK 58 / React Native 0.88 (ADR 0008). Read
`docs/handbook/clients/android.md` and `DESIGN.md` first. Non-negotiable:

- Native components, not a WebView of the web client.
- Shares `@cindl/contracts`, `client-core`, `client-react`, `hermes-adapter` and
  `@cindl/tokens`; no forked types or styles. Colours come from `useTheme()`
  only (lint rejects raw colours).
- Tokens only in secure storage (Android Keystore); nothing secret in
  AsyncStorage or logs. Storage modules are imported only in `src/platform`
  (lint: `cindl-android/storage-in-platform`).
- System back closes sheets and overlays first; IME never covers the composer;
  48dp targets (`ANDROID_TOUCH_TARGET`); TalkBack labels match the web labels;
  respect font scale and reduced motion.
- Native projects are generated by prebuild and not committed.
- Android SDK terms: the owner approved Google's Android SDK License Agreement
  (`android-sdk-license`) for Cindl APK builds and emulator tests on
  GitHub-hosted runners only (2026-11-03). Never install or run SDK packages
  on development machines or personal devices, never run
  `sdkmanager --licenses` or write licence files, and stop at any other
  licence or terms screen (store, browser first run). Packages are pinned in
  `sdk/android-sdk.ts` and checked by `scripts/android-sdk.ts`; the generated
  project keeps `android.builder.sdkDownload=false` (fail closed). Test APKs
  are signed with a throwaway per-run key, never the public debug key or a
  store key.
- APKs carry Cindl's licence and every third-party notice in
  `assets/licenses/`: npm packages (`scripts/third-party-notices.ts`) and the
  native libraries Gradle adds (`scripts/native-notices.ts`, which keeps the
  licence files the Android build would drop). `scripts/check-apk.ts` fails
  without them; never trim or hand-edit them.

Working here:

- Checks without an SDK: `pnpm --filter @cindl/android typecheck`,
  `pnpm exec vitest run --project android`, `expo export --platform android`
  with `scripts/check-bundle.ts`, and `expo prebuild` with
  `scripts/check-native-project.ts` (run heavy builds under the shared build
  lock on shared machines).
- UI talks only to `CindlClientApi` via `@cindl/client-react`; read client
  state maps only through `entry`/`hasEntry`. Real builds run client-core's
  `createDirectClient` (`src/platform/direct.ts`) with one PKCE
  implementation, the adapter's `NativeAuth`; `src/auth/loopback.ts` is only
  the browser leg. Platform pieces (storage, sockets, crypto) live in
  `src/platform`; the Kotlin loopback listener in `modules/cindl-loopback` has
  JUnit tests that CI runs on a plain JVM. Client tests run against
  `@cindl/fixtures/fake-hermes` (read-only to this stream).
- Synthetic fixtures load only in `src/platform/client.ts` behind
  `EXPO_PUBLIC_CINDL_DEMO=1`; `metro.config.cjs` empties them in other bundles.
- Sheets and dialogs use `src/overlay` (in-tree, so keyboard insets and back
  order work); handle back with `useBackHandler`, never `BackHandler` directly.
- Request identity, clarify drafts and answers go through
  `src/talk/requests.ts` only; `sendAnswer` refuses prompts Cindl never
  answers (`assertAnswerable`) before anything is sent.
- Keep pure logic out of components so it can be tested without React Native.
- `eslint.config.mjs` never sets a root rule's options again (that replaces the
  root's list for those files); Android checks are rules in `lint/rules.mjs`,
  tested in `test/lint-rules.test.ts`.
- Emulator tests live in `e2e/` and run only in CI (`e2e/run.ts`); their pure
  parts (UI dump parsing, 48dp audit, fake Hermes auth server) are unit-tested
  in `test/e2e.test.ts`. Use accessibility labels as selectors, so a renamed
  label breaks a test rather than TalkBack silently.
