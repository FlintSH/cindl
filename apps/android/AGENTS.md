# apps/android

Native Android app on Expo / React Native (ADR 0008). Non-negotiable:

- Native components, not a WebView of the web client.
- Shares `@cindl/contracts`, `client-core`, `client-react`, `hermes-adapter` and
  `@cindl/tokens`; no forked types or styles.
- Tokens only in secure storage (Android Keystore); nothing secret in
  AsyncStorage or logs.
- System back closes sheets and overlays first; IME never covers the composer;
  44dp targets; TalkBack labels match the web labels; respect font scale and
  reduced motion.
- Native projects are generated by prebuild and not committed.
- Do not accept Android SDK or store terms on the development VM. Build APKs
  in CI on runners with a licensed SDK; debug-signed only.
