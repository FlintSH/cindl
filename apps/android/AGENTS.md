# apps/android

Native Android app on Expo SDK 58 / React Native 0.88 (ADR 0008). Read
`docs/handbook/clients/android.md` and `DESIGN.md` first. Non-negotiable:

- Native components, not a WebView of the web client.
- Shares `@cindl/contracts`, `client-core`, `client-react`, `hermes-adapter` and
  `@cindl/tokens`; no forked types or styles. Colours come from `useTheme()`
  only (lint rejects raw colours).
- Tokens only in secure storage (Android Keystore); nothing secret in
  AsyncStorage or logs.
- System back closes sheets and overlays first; IME never covers the composer;
  44dp targets; TalkBack labels match the web labels; respect font scale and
  reduced motion.
- Native projects are generated by prebuild and not committed.
- Do not accept Android SDK or store terms on the owner's behalf, on shared
  development machines or in CI: no `sdkmanager`, licence files, emulator
  actions or SDK package installs without the owner's approval. The generated
  project keeps `android.builder.sdkDownload=false` (fail closed). APKs, once
  approved, are debug-signed only.

Working here:

- Checks without an SDK: `pnpm --filter @cindl/android typecheck`,
  `pnpm exec vitest run --project android`, `expo export --platform android`
  with `scripts/check-bundle.ts`, and `expo prebuild` with
  `scripts/check-native-project.ts` (run heavy builds under the shared build
  lock on shared machines).
- UI talks only to `CindlClientApi` via `@cindl/client-react`; read client
  state maps only through `entry`/`hasEntry`. Platform pieces (storage,
  sockets, crypto, sign-in) live in `src/platform` and `src/auth`; the Kotlin
  loopback listener in `modules/cindl-loopback` has JUnit tests that CI runs on
  a plain JVM.
- Synthetic fixtures load only in `src/platform/client.ts` behind
  `EXPO_PUBLIC_CINDL_DEMO=1`; `metro.config.cjs` empties them in other bundles.
- Sheets and dialogs use `src/overlay` (in-tree, so keyboard insets and back
  order work); handle back with `useBackHandler`, never `BackHandler` directly.
- Request identity, clarify drafts and answers go through
  `src/talk/requests.ts` only.
- Keep pure logic out of components so it can be tested without React Native.
