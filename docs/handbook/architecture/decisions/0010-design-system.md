# 0010 Shared tokens and the Conversation Desk

**Status:** Accepted

**Decision.** One token package drives every client; contrast pairings are
tested in both themes. Four destinations (Talk, Work, Library, Agent) with the
conversation as the anchor, a searchable history popover instead of a thread
column, and a contextual working margin. Fonts are bundled locally under OFL.
Details in `DESIGN.md`.
