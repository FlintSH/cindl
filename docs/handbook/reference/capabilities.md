# Capabilities

A capability says whether a feature can be used on the current connection,
why, and how that was established. States: `available` (negotiated or probed
now), `limited` (usable with a stated limitation), `unavailable` (supported by
this Hermes version but not right now), `unsupported` (not exposed by this
version or transport, or not implemented in Cindl), `unknown` (not checked;
never shown as working).

The direct client negotiates the map per connection in
`packages/hermes-adapter/src/negotiate.ts` from public discovery
(`GET /api/status`), the WebSocket handshake (`gateway.ready`,
`client.capabilities`, `gateway.capabilities` or `runtime.describe`) and one
read-only probe (`display.status`). Nothing is set up, started or installed to
find out. Results can differ per instance. **Agent → Runtime** shows whatever
the current client reports, including the synthetic demo's states. None of
this has been verified against a live instance yet; see the
[Hermes v0.22.5 reference](./hermes-v0.22.5.md).

Signed out, offline or unconfigured, every capability below except the fixed
`unsupported` ones is `unavailable` with the reason. On a `session_authority`
(canonical) connection, which `hermes serve` v0.22.5 does not offer, the
session and chat capabilities are `unsupported`: Cindl negotiates
`runtime.describe` but does not implement canonical sessions yet.

| ---------------------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `chat.stream`          | Send messages and stream replies     | `prompt.submit`, `message.*` events                                                                                                | available                                                                                                                                              |
| `chat.interrupt`       | Stop the current turn                | `session.interrupt`                                                                                                                | available                                                                                                                                              |
| `chat.steer`           | Redirect a running turn              | `session.steer`                                                                                                                    | unsupported: no Cindl operation yet                                                                                                                    |
| `sessions.list`        | List conversations                   | `session.list`                                                                                                                     | available                                                                                                                                              |
| `sessions.create`      | Start a side conversation            | `session.create`                                                                                                                   | available                                                                                                                                              |
| `sessions.history`     | Load a transcript                    | `session.resume` (attaches and returns the transcript)                                                                             | available                                                                                                                                              |
| `sessions.replay`      | Catch up after reconnect             | `session.events.since` (512 events or 4 MiB per session, in memory)                                                                | limited: not durable; Cindl reloads history after a restart or truncation                                                                              |
| `sessions.rename`      | Rename a conversation                | `GET /api/sessions/{id}/mutation-snapshot` + `PATCH /api/sessions/{id}` (revision-fenced); `session.title` before the first prompt | available                                                                                                                                              |
| `requests.approval`    | Answer command approvals             | server request `approval`, offered in `client.capabilities`                                                                        | available; `once` and `deny` only                                                                                                                      |
| `requests.clarify`     | Answer clarifying questions          | server request `clarify`, offered in `client.capabilities`                                                                         | available; one reply for the whole set                                                                                                                 |
| `activity.tools`       | See tool steps                       | `tool.*` events                                                                                                                    | available                                                                                                                                              |
| `activity.subagents`   | See delegated work                   | `subagent.*` events                                                                                                                | available                                                                                                                                              |
| `activity.processes`   | See background processes             | `process.list`                                                                                                                     | unsupported: no Cindl operation yet                                                                                                                    |
| `routines.read`        | List cron jobs                       | `cron.manage list` (with `include_disabled`)                                                                                       | available                                                                                                                                              |
| `routines.write`       | Pause or resume cron jobs            | `cron.manage pause`/`resume`                                                                                                       | available, owner-confirmed                                                                                                                             |
| `skills.read`          | Read skills                          | `GET /api/skills`, `GET /api/skills/content`                                                                                       | available                                                                                                                                              |
| `skills.write`         | Edit a skill                         | `PUT /api/skills/content` (full rewrite)                                                                                           | limited: no server compare-and-swap or backup; Cindl compares the SHA-256 of the reviewed version first                                                |
| `soul.read`            | Read SOUL.md                         | `GET /api/profiles/{name}/soul`                                                                                                    | available                                                                                                                                              |
| `soul.write`           | Edit SOUL.md                         | `PUT /api/profiles/{name}/soul` (atomic full rewrite)                                                                              | limited: no server compare-and-swap or backup; Cindl compares the SHA-256 of the reviewed version first                                                |
| `memory.overview`      | Memory provider metadata             | `GET /api/memory` (sizes and providers)                                                                                            | available                                                                                                                                              |
| `memory.text`          | Read or edit memory entries          | `GET /api/learning/graph`, `GET/PUT/DELETE /api/learning/node` (fingerprinted ids)                                                 | unsupported: Hermes exposes it, Cindl has adapter functions but no reviewed operation until the contract change lands; no undo in Hermes               |
| `connections.mcp`      | MCP server health                    | `mcp.servers.status` (cached, never probes)                                                                                        | available                                                                                                                                              |
| `connections.accounts` | Account coverage evidence            | none safe (`connectors.*` can create guest identities)                                                                             | unsupported                                                                                                                                            |
| `computer.view`        | View the agent-owned screen          | `display.status`; live picture via `display.observe` (RFB)                                                                         | unknown until probed; limited while running (state and controller only, no live picture yet); unavailable when stopped; unsupported when not installed |
| `computer.control`     | Take the input lease                 | `display.observe` (viewer id) + `display.lease.acquire` / `release`                                                                | available while the screen runs; follows `computer.view` otherwise                                                                                     |
| `artifacts.list`       | List artifacts                       | none at v0.22.5                                                                                                                    | unsupported                                                                                                                                            |
| `attachments.upload`   | Attach files to a message            | `file.attach` exists upstream; not wired in Cindl                                                                                  | unsupported in Cindl                                                                                                                                   |
| `presence.unified`     | One live session across all surfaces | `gateway.ready.session_authority` + canonical protocol                                                                             | unavailable: the sidecar does not prove one session authority                                                                                          |

A Hermes in loopback-token mode (`auth_required: false`) is reported as an
incompatible link, not as a set of capabilities: Cindl needs a sign-in
provider and never reads the per-process dashboard token.
